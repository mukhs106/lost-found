# Images Directory

This directory should contain 112 personal images organized by year (1990-2025).

## Structure

```
images/
├── 2025/
│   ├── image_name_1.jpg
│   └── image_name_2.jpg
├── 2024/
│   ├── image_name_3.jpg
│   └── ...
├── 2023/
└── ... (down to 1990/)
```

## Image Requirements

- **Total**: 112 images spanning 1990-2025
- **Format**: JPG, PNG, or SVG
- **Naming**: Descriptive names (e.g., `morning_ritual.jpg`, `childhood_insects.jpg`)
- **Organization**: Organized by year in subdirectories
